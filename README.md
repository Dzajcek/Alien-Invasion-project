# Alien Invasion - Python Game

This is a 2D arcade game built with Python and Pygame. While the core logic is based on the "Python Crash Course" book by Eric Matthes, I have significantly customized and expanded the project with my own features.

## Features & My Contributions
* **Difficulty Levels**: I implemented a custom difficulty system that increases the challenge as the player progresses.
* **Sound Effects**: Added custom audio effects, including a shooting sound triggered every time a bullet is fired.
* **Visual Customizations**: Modified the game's appearance and colors to enhance the user experience.

## Technologies Used
* Python 3
* Pygame library

## How to Run
1. Make sure you have Python installed.
2. Install Pygame: `pip install pygame`
3. Run the main file: `python alien_invasion.py`
